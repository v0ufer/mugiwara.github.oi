Правила сервера чистого выживания

1 Нарушения, связанные с чужим имуществом

1. Использование чужих ферм без разрешения владельца.
2. Использование чужих трейдхоллов без разрешения.
3. Действия с чужой территорией без согласия (радиус 50 блоков от построек).
Особенно запрещено строительство с целью оскорбления хозяина.
4. Действия с чужими хранилищами без согласия.
4.1 Принудительный обмен ресурсами.
4.2 Разрушение чужих хранилищ с целью навредить.
5. Гриферство в любом виде без соглашения.

2 Общение в игре и Discord

2.1 Личные оскорбления и переход на личности.
2.2 Флуд, спам, крик (капс) без причины.
2.3 Обсуждение политики, религии и провокационных тем.
2.4 Доксинг (распространение личных данных).
2.5 Ложные доносы и обман администрации.

3 Административные нарушения

3.1 Обход бана / мута.
3.2 Отказ предоставить скриншоты по запросу администрации.
3.3 Систематическое токсичное поведение.
Нарушение правил может повлечь предупреждение, мут или бан.
