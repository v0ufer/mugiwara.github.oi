Инструкция по настройке Whitelister

1. Установите плагин Whitelister на сервер Minecraft.

2. В файле plugins/Whitelister/config.yml включите API.

3. Введите URL и ключ в поля выше.

4. Нажмите «Проверить соединение» для теста.

✅ После настройки при принятии заявки игрок будет автоматически добавлен в вайтлист!
