Инструкция по настройке TabernaConnector

1. Скачайте плагин TabernaConnector и поместите в папку plugins сервера.

2. Перезапустите сервер для генерации конфига.

3. Откройте plugins/TabernaConnector/config.yml и настройте:

port: 8081
secret-key: "ваш_секретный_ключ_здесь"
allowed-commands:
  - "whitelist add %player%"
  - "list"
  - "say Hello from web"

4. Введите URL (http://ip-сервера:8081) и ключ в поля выше.

5. Нажмите «Проверить соединение» для теста.

✅ После настройки при принятии заявки игрок будет автоматически добавлен в вайтлист!
